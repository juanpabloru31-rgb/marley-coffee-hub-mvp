# Hub B2B Marley Coffee — MVP académico

Prototipo funcional en Streamlit. Datos y procesos ficticios. No es una plataforma oficial de Marley Coffee ni Dicalla SpA.

## Ejecutar en Windows

1. Instala Python 3.11 o superior.
2. Abre una terminal en esta carpeta.
3. Ejecuta `py -m pip install -r requirements.txt`.
4. Ejecuta `py -m streamlit run app.py`.
5. Abre la URL local que muestra la terminal.

## Publicar en Streamlit Community Cloud

1. Crea un repositorio de GitHub y sube `app.py` y `requirements.txt`.
2. En https://share.streamlit.io crea una app seleccionando el repositorio y el archivo principal `app.py`.
3. Publica y copia el enlace generado.

## Limitaciones deliberadas

- El acceso es una selección de perfil, no autenticación real.
- No se guardan datos permanentemente ni se comparten entre usuarios.
- No existen integraciones ERP, CRM, WMS, pagos, telemetría ni servicio técnico real.
- No ingresar información personal ni comercial real.
- Los precios y pedidos son ficticios.
